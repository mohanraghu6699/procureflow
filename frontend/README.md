# ProcureFlow — Frontend

React + TypeScript (Vite) single-page app for the ProcureFlow purchase-to-pay application.

```bash
npm install
cp .env.example .env    # API base URL, defaults to http://localhost:8000
npm run dev             # http://localhost:5173
```

Setup for the whole project (backend, database, demo accounts, architecture) is in the [root README](../README.md).
